# Task 2: Limits of Exact Counting and Flajolet–Martin

## 1. 실험 목적

데이터 크기를 증가시키면서 정확한 고유 항목 개수 계산과 Flajolet–Martin(FM) 추정 알고리즘의 실행 시간, 메모리 사용량 및 추정 정확도를 비교하였다.

## 2. 실험 환경

- 운영체제: Windows 11
- 프로세서: Intel64 Family 6 Model 140 Stepping 1, GenuineIntel
- Python: 3.12.2

## 3. 실험 결과

| 데이터 크기 (n) | 실제 고유 항목 수 | 정확 계산 시간 (초) | 정확 계산 메모리 (MB) | FM 추정값 | FM 실행 시간 (초) | FM 메모리 (KB) | 추정 비율 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 100,000 | 36,702 | 0.35 | 3.93 | 47,524 | 92.21 | 4.50 | 1.29 |
| 400,000 | 146,970 | 1.66 | 11.59 | 161,583 | 344.10 | 4.50 | 1.10 |
| 640,000 | 235,071 | 2.51 | 20.54 | 183,761 | 532.75 | 4.50 | 0.78 |
| 1,600,000 | 587,625 | 5.90 | 46.65 | 937,816 | 1,391.20 | 4.50 | 1.60 |

*추정 비율은 FM 추정값을 실제 고유 항목 수로 나눈 값이다. 1보다 크면 실제보다 크게, 1보다 작으면 작게 추정한 것이다. 메모리는 JSON에 기록된 바이트 값을 MB 또는 KB로 환산하고 반올림하였다.*

## 4. 결과 분석

### A1. 데이터 크기 범위

100,000개부터 1,600,000개까지 총 4개의 데이터 크기를 실험하였다. 가장 큰 데이터 크기는 가장 작은 데이터 크기의 16배이므로, 요구된 데이터 크기 범위를 충족하였다.

### A2. 대규모 데이터 실험과 한계

추가로 데이터 크기 6,400,000개를 대상으로 실험하였다. 그러나 FM 추정 과정에서 실행 시간이 길어져 실험을 중단하였다. 해당 실행은 완료되지 않았으므로 이 데이터 크기에 대한 측정 결과는 확보하지 못했다.

완료된 실험 중 가장 큰 1,600,000개 데이터에서는 정확 계산에 약 5.90초가 걸렸으며, 약 46.65 MB의 메모리를 사용하였다. 6,400,000개 실험은 FM 계산 도중 중단했으므로, 정확 계산이 실패한 지점이라고 단정할 수는 없다.

### A3. 메모리 사용량 비교

데이터 크기가 100,000개에서 1,600,000개로 증가하면서 정확 계산의 메모리 사용량은 약 3.93 MB에서 46.65 MB로 증가하였다. 반면 FM 알고리즘의 측정 메모리는 약 4.50 KB로 거의 일정하게 유지되었다.

### A4. 메모리 증가 특성

정확 계산은 고유 항목을 저장하고 관리해야 하므로 데이터가 커질수록 메모리 사용량이 증가한다. 반면 FM은 데이터 전체를 저장하는 대신 해시 결과를 이용한 요약 정보를 유지하므로 상대적으로 적은 메모리를 사용한다.

### A5. FM 추정 정확도

실험에서 FM 추정값은 실제 고유 항목 수의 약 0.78~1.60배 범위에 있었다. 예를 들어 400,000개 데이터에서는 실제 고유 항목 수가 146,970개이고 FM 추정값은 약 161,583개로, 실제보다 약 9.9% 크게 추정하였다. 반면 640,000개 데이터에서는 실제보다 작게 추정하였다.

따라서 FM은 메모리를 적게 사용하는 장점이 있지만, 데이터에 따라 추정 오차가 발생할 수 있음을 확인하였다.

### A6. 실험 환경 기록

실험은 Windows 11, Python 3.12.2 환경에서 수행하였다. 프로세서 정보는 실험 결과 파일인 `limits.json`에 기록하였다. 실험 중에는 대규모 FM 추정 작업의 실행 시간이 길어질 수 있음을 확인하였다.

## 5. 결론

정확 계산은 고유 항목 수를 정확히 구할 수 있지만, 데이터 크기가 커질수록 메모리 사용량이 증가한다. FM 알고리즘은 약 4.50 KB의 메모리만 사용하여 메모리 효율이 높았으나, 이번 구현에서는 실행 시간이 길었고 추정값에도 오차가 발생하였다. 또한 6,400,000개 실험은 FM 계산 시간이 길어 중단했으므로, 해당 크기의 결과는 결론에 포함하지 않았다.
